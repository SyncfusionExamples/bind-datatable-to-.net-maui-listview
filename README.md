# How to bind data from the DataTable to .NET MAUI ListView(SfListView)?

The [.NET MAUI ListView](https://www.syncfusion.com/maui-controls/maui-listview) allows you to bind data directly from the [DataTable](https://docs.microsoft.com/en-us/dotnet/api/system.data.datatable?view=net-6.0) by adding its rows to the collection and binding them to the [ItemsSource](https://help.syncfusion.com/cr/maui/Syncfusion.Maui.ListView.SfListView.html#Syncfusion_Maui_ListView_SfListView_ItemsSource) property.

Steps:
1. Populate items into the DataTable and add each DataRow to the collection.
2. Bind the ViewModel collection to the ItemsSource property. Since DataRow is of array type, you can directly bind to the row data using ItemsArray.

Download the
complete sample on [GitHub](https://github.com/SyncfusionExamples/bind-datatable-to-.net-maui-listview "https://github.com/SyncfusionExamples/bind-datatable-to-.net-maui-listview").
